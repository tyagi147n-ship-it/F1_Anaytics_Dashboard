# 🏎️ F1 Analytics Dashboard

An interactive **Formula 1 Analytics Dashboard** built using Python, Pandas, NumPy, Plotly, and Streamlit.

The dashboard transforms Formula 1 racing data into interactive visualizations and insights, making it easier to explore driver performance, team performance, race results, and other F1 statistics.

---

## 📊 Project Overview

Formula 1 generates a large amount of historical racing data. Analysing this data manually can be difficult and time-consuming.

This project provides an interactive dashboard where users can explore F1 data through charts, tables, and visual analytics.

The application is developed using **Streamlit** and uses **Plotly** to create interactive visualizations.

---

## 🚀 Features

- 🏁 Formula 1 race data analysis
- 👨‍🏎️ Driver performance analysis
- 🏆 Constructor/team performance analysis
- 📈 Interactive charts and graphs
- 📊 Race statistics and results
- 🔎 Data filtering and exploration
- 📉 Performance comparison
- 🖥️ Interactive Streamlit dashboard
- 📁 CSV-based data processing
